# NeonTag

Linux 图片标注工具，Python 3.10–3.13，`python main.py` 监听 `0.0.0.0:8080`。前端为原生 HTML/CSS/JavaScript，后端 Flask + Waitress，默认黑、灰、荧光绿。

模型为 Qwen/Qwen3-VL-4B-Instruct（默认）和 Qwen/Qwen3-VL-8B-Instruct。选择模型后检查本地完整性，缺失时通过 ModelScope 下载到项目 models 子目录。使用 Transformers 的 Qwen3VLForConditionalGeneration 本地推理。

支持输入服务器本地 Qwen2-VL、Qwen2.5-VL、Qwen3-VL 标准权重目录，验证家族及配置/处理器/词表/全部权重，按家族选择 Transformers 模型类。相对路径或用户目录在检查后固定为绝对路径。预量化模型暂不支持。

工作台默认暗色，可切换日间主题。全页固定高度，任务列表为主要区域；设置分三个标签页并可收起，测试默认折叠且抽图使用弹窗，日志可放大或折叠。长内容在区域内部滚动。任务可展开分页图片，点击图片打开左图右标签弹窗；运行期间轮询更新结果，暂停或完成后可编辑，未保存输入不会被轮询或迟到的保存响应覆盖。

任务日志包含创建、启动、模型准备、逐图生成/重试/完成/失败、暂停/取消/恢复、编辑及导出，每秒刷新，最近 500 条持久化在任务记录，输出保持干净。

输入为服务器文件夹路径，默认读取当前层图片。缩放按钮对目录图片进行等比例缩放并统一重命名，长边 1024，前缀 image，格式 JPG；先在项目 .state 下完整备份，再替换，失败回滚。输出默认 TXT，图片标签合放；分开放入 images 和 labels。拒绝已有文件冲突和输入输出目录重叠。

默认提示词要求英文逗号分隔的、只基于视觉证据的标签。最少标签数量默认 20，触发词为可选前缀；清洗、去重并检查数量，不足重试，仍不足记失败，不填充虚构词。

测试默认随机两张，先创建预览，用户确认再生成，存放 .state/tests/job-id。批量默认全部，可手动选择。任务配置固定，暂停和取消均可继续，已成功图片不重复推理。任务记录采用原子 JSON，保存在 .state/jobs；进程重启将运行中任务转为暂停，继续时检查输入及输出完整性。界面支持审核、修改已生成标签和重试失败项。

压缩快照只包含任务输出图片、标签，默认 ZIP，另有 TAR.GZ 和 RAR（系统 rar 程序）。压缩包与输出目录同级，拒绝覆盖既有压缩包。配置、任务记录、批处理临时文件、备份在项目 .state。人工标签编辑使用输出同级的临时文件完整写入后原子替换，不进入输出目录，兼容跨盘输出。

不提供公开互联网身份管理；面向可信服务器使用环境，部署说明注明服务器路径、显卡依赖和端口访问。
